# Popups & Notifications

Beyond the inline components, Aetheris has a set of popup surfaces. These render above the window and stay in sync with the active theme.

* [Dropdown Popup](dropdown-popup.md) — the list that opens from a dropdown component.
* [Color Picker Popup](color-picker-popup.md) — the colour chooser.
* [Tooltip](tooltip.md) — hover labels.
* [Notifications](notifications.md) — toasts for alerts, errors and updates.

You rarely create these directly — dropdowns, colour pickers and toggles open them for you. They're documented here so you know what's happening under the hood and can theme them.
