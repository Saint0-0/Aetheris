# Components

Everything you can add to a section. Each page lists the options, the methods, and a short example.

Most components also share four methods: `:SetName(string)`, `:SetVisible(bool)`, `:GetVisible()`, and `:Destroy()`. Only the extras are listed on each page.

| Component | What it does |
| --- | --- |
| [Toggle](components/toggle.md) | On/off switch, with an optional confirm dialog. |
| [Slider](components/slider.md) | Draggable value bar. |
| [Stepper](components/stepper.md) | Number with plus and minus buttons. |
| [Keybind](components/keybind.md) | Captures a keyboard key. |
| [Text Input](components/text-input.md) | Single-line text field. |
| [Dropdown](components/dropdown.md) | Popup list, single or multi select. |
| [Color Picker](components/color-picker.md) | Swatch that opens the picker popup. |
| [Radio Button Group](components/radio-button-group.md) | Mutually exclusive choices. |
| [Radio Button](components/radio-button.md) | One standalone choice. |
| [Progress Bar](components/progress-bar.md) | Filled bar for min-to-max values. |
| [Status](components/status.md) | Heading plus coloured status lines. |
| [Live Stat](components/live-stat.md) | Big rolling number with a change line. |
| [Console](components/console.md) | Scrollback log panel. |
| [Code View](components/code-view.md) | Highlighted code block, optionally editable. |
| [Video](components/video.md) | Inline video frame. |
| [Viewport](components/viewport.md) | Renders a player's character. |
| [Button](components/button.md) | A row you click. |
| [Label](components/label.md) | One line of text in a container. |
| [Paragraph](components/paragraph.md) | Title with a description block. |
| [Divider](components/divider.md) | Thin horizontal separator. |
