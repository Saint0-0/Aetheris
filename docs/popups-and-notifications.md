# Popups & Notifications

Beyond the inline components, Aetheris has a set of popup surfaces. They render above the window and follow the active theme.

* [Notifications](popups-and-notifications/notifications.md) — toasts for alerts, errors and updates, plus the confirm dialog.
* [Tooltip](popups-and-notifications/tooltip.md) — the hover label on sidebar tabs.

Dropdown lists and colour pickers are popups too, but you rarely create them yourself — the dropdown and colour picker components open them for you. They're documented on their own component pages.

Everything here themes automatically. To restyle popups as a whole, use the `Popup*` and `Notification*` theme keys (see [Custom Themes](theming/custom-themes.md)).
